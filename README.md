# ♠ Friends Hold'em

친구들과 즐기는 **실시간 온라인 텍사스 홀덤 (토너먼트 모드)**.
방 코드를 만들어 공유하면, 각자 휴대폰·노트북 브라우저로 접속해 함께 플레이합니다.

## 주요 기능

- **실시간 멀티플레이** — Socket.IO 기반, 최대 9인 테이블
- **방 코드 입장** — 4자리 코드를 친구에게 공유 (예: `K7QP`)
- **토너먼트 모드** — 블라인드가 레벨마다 자동 상승, 앤티 도입, 탈락제, 마지막 1인 우승
- **정확한 룰 구현** — No-Limit Hold'em, 사이드 팟, 최소 레이즈, 올인, 헤즈업 블라인드 규칙
- **7카드 핸드 평가기** — 로열/스트레이트 플러시부터 하이카드까지, 키커·휠(A-5) 처리
- **재접속 지원** — 연결이 끊겨도 같은 닉네임으로 다시 들어오면 자리 인수
- 모바일 대응 UI, 채팅, 액션 로그

## 빠른 시작 (로컬)

```bash
cd poker
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속.

같은 와이파이의 친구들은 호스트의 내부 IP(예: `http://192.168.0.10:3000`)로 접속하면 바로 같이 플레이할 수 있습니다.

## 테스트

```bash
npm test                 # 핸드 평가기 단위 테스트 (15개)
node test/game.sim.js    # 봇 200게임 시뮬레이션 (크래시·칩 보존 검증)

## 인터넷으로 친구 초대하기 (배포)

이 게임은 **상시 연결되는 WebSocket 서버**가 필요합니다. 서버리스(Vercel/Netlify Functions)에는
부적합하므로, 일반 Node 서버를 지원하는 호스팅을 권장합니다.

### Render (무료 티어, 권장)

1. 이 `poker` 폴더를 GitHub 저장소에 푸시
2. [render.com](https://render.com) → New → **Web Service** → 저장소 연결
3. 설정:
   - Build Command: `npm install`
   - Start Command: `npm start`
   - 환경변수: 없음 (포트는 `process.env.PORT` 자동 사용)
4. 배포되면 나오는 URL(`https://....onrender.com`)을 친구에게 공유

### Railway / Fly.io

- **Railway**: 저장소 연결 후 자동 감지, `npm start`로 실행. 도메인 발급 버튼 클릭.
- **Fly.io**: `fly launch` → Node 감지 → `fly deploy`. 내부 포트 3000 지정.

> 어떤 플랫폼이든 핵심은 `npm start`(=`node server.js`)를 그대로 실행하고
> `PORT` 환경변수를 열어주는 것입니다. 코드 수정은 필요 없습니다.

## 게임 방법

1. 닉네임 입력 후 **방 만들기** (시작 스택·레벨당 핸드 수 설정 가능)
2. 생성된 4자리 코드를 친구에게 공유
3. 친구들은 **방 참여** 탭에서 코드 입력해 입장
4. 방장이 **게임 시작** (최소 2명)
5. 자기 차례에 폴드 / 체크·콜 / 레이즈(슬라이더·½팟·팟·올인) 선택
6. 블라인드는 설정한 핸드 수마다 상승. 칩이 0이 되면 탈락, **마지막 1인이 우승**

## 프로젝트 구조

```
poker/
├── server.js              # Express + Socket.IO 서버, 방·세션 관리
├── src/
│   ├── deck.js            # 카드·셔플(crypto 기반)
│   ├── handEvaluator.js   # 7카드 → 최고 5카드 패 평가·비교
│   └── game.js            # 게임 상태머신 + 토너먼트(블라인드/사이드팟/탈락)
├── public/
│   ├── index.html         # 로비·대기실·테이블 화면
│   ├── style.css          # 펠트 테이블 UI
│   └── client.js          # 소켓 통신·렌더링·액션
└── test/
    ├── handEvaluator.test.js
    └── game.sim.js
```

## 룰 세부사항

- 시작 스택 기본 1,500 / 레벨당 8핸드 (방 만들 때 변경 가능)
- 블라인드 스케줄: 10/20부터 13레벨까지 점진 상승, 레벨 5부터 앤티 도입
- 사이드 팟: 올인 기여도 레이어별로 정확히 분배, 폴드한 데드머니 포함 처리
- 헤즈업(2인): 버튼이 스몰블라인드, 프리플랍은 버튼부터 액션
